SilverMachine runs a classic computer role-playing engine in your browser. Your game folder supplies the world, characters and artwork.

Supported: the GOG release (recommended, buy it) or the original Collector's CD.

Click the game to restore keyboard and mouse control.

F10: Save / Load · F2: Area · Enter: Select · Esc: Back

Saves and settings stay in this browser. Export a backup before clearing browser data or changing devices. Import replaces the saved slots and settings in this browser.

Chrome and Edge are the first supported browsers. Other browsers can use the compatibility picker if their game runtime is supported; Firefox and Safari have not been qualified.
