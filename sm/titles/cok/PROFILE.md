**Initial main menu / route 0%. Menu boots and renders; town is blocked on the
native character-load rule binding. This is not a playable title.**

`sm.engine.Session(profile=cok, slot=None, directory=EXTERNAL_FOLDER)`.

Import public primitives (`sm.dax`, `sm.ecl`, `sm.rec.Record`, `sm.files`,
`sm.search`, `sm.replay`, `sm.engine`, `sm.ui.art`). Keep originals, decompressed
content and strings in memory. Keep all title changes out of the release manifest.
Do not install process-global SSB monkeypatches to select another title. A VMBinding
belongs to one content provider; share it only between instances of that provider.
Host and VM factories do not parameterize the retained rule units automatically.
Every character load must perform the native post-load calculations before play.

Check originals with `python -I -B sm/titles/cok/check.py --folder EXTERNAL_FOLDER`;
run `python -B herdr/tools/source_guard.py` as a separate gate. Current check:
16 tables, 88 monsters, 15 maps, 22 scripts / 13,547 instructions / 58 opcodes,
18 starter-save files identical. Field editing is lossless; gameplay semantics
and live pointer reconstruction are not certified by these checks.

Reproduce the initial-menu check with
`python -I -B sm/titles/cok/_menu_check.py --folder EXTERNAL_FOLDER`.
It exports a frame to a new external temporary directory, writes hashes/counts
to `COK_MENU_GATE.json`, and closes the pending menu without selecting an action.
Menu actions remain enabled as in the original; unbound actions raise explicitly.
The full SSB/DQK gate is `_regression.py FRESH_LABEL`; it refuses to overwrite a
prior report or refresh the immutable witness hashes. S1, S2b, S3 and S4_MENU pass.
